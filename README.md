# nivohavi/homebrew-tap

Homebrew casks for my apps.

```sh
brew trust nivohavi/tap   # newer Homebrew asks you to trust third-party taps once
brew install --cask nivohavi/tap/primesnap
```

| Cask | App |
|---|---|
| `primesnap` | [PrimeSnap](https://github.com/nivohavi/primesnap): capture, frame, annotate and redact screenshots from your menu bar |
